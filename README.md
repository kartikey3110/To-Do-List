# To-Do List Manager ✅

## About the Project
To-Do List Manager is a simple web-based mini project developed using HTML, CSS, and JavaScript. It helps users organize their daily tasks, track completed work, and manage pending tasks efficiently.

## Features
- Add new tasks.
- Mark tasks as completed.
- Delete individual tasks.
- Search for tasks by name.
- Sort tasks alphabetically (A–Z).
- View total, pending, and completed task counts.
- Save tasks in the browser using Local Storage.
- Retain tasks after refreshing the page.

## Technologies Used
- HTML – Structure of the website
- CSS – Styling and layout
- JavaScript – Functionality and logic
- Browser Local Storage – Saving task data

## DSA Concepts Used
- Arrays
- Objects
- Searching
- Sorting
- Array Traversal
- Data Filtering

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Find the index.html file.
4. Double-click index.html to open it in a web browser.
5. Add, search, complete, and delete tasks.

## Project Objective
The objective of this project is to apply Data Structures and Algorithms concepts to a practical task-management application.

## Limitations
- Tasks are saved only in the current browser's Local Storage.
- Tasks are not synchronized across devices.
- The project does not include user login or cloud storage.
